# 📋 セキュアなCRUDアプリ作成の全体ロードマップ
## ステップ1：土台作りと環境の準備

* セキュアなフォルダ構成（my-crud-app と public）を作る
![ディレクトリ構成](file%20_structure.png)  

* Gitの除外設定（.gitignore）と秘密情報置き場（.env）を置く

* MariaDBで専用のデータベース（secure_app_db）とテーブル（items）を作る

## ステップ2：安全なデータベース接続ファイルの作成 (db.php)

* .env からパスワードなどの機密情報を安全に読み込み、PDOでデータベースに接続する共通パーツを作る

## ステップ3：一覧表示と新規登録機能を作る (public/index.php)

* データベースから商品リストを画面にずらっと表示（Read）する

* 新しい商品をフォームから登録（Create）できるようにする

## ステップ4：編集・更新機能を作る (public/edit.php)

* 既存のデータを取得してフォームに表示し、内容を書き換えて更新（Update）できるようにする

## ステップ5：削除機能を作る (public/delete.php)

* 不要なデータをポチッと削除（Delete）できるようにしてアプリを完成させる！
